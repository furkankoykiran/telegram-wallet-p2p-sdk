# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.0] - 2025-02-24

### Added

- Initial release of the Telegram Wallet P2P SDK Ecosystem.
- **Python SDK**: Async client with Pydantic models and analytics.
- **Node.js SDK**: TypeScript client using native fetch, zero dependencies.
- **MCP Server**: AI-ready tools for market data inspection.
- Full test coverage and CI/CD integration.
